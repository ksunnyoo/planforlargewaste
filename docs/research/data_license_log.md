# 데이터 이용허락 확인 기록 (추가만 하고 수정하지 않음)

> 07_DATA_TERMS.md 5절 체크리스트 4번에 따라 만든 기록입니다. 법률 자문이 아니며, 상업화 전에 원문을 다시 확인해야 합니다.

| 확인 일시 | 대상 | 확인한 내용 | 근거 | 판정 |
|---|---|---|---|---|
| 2026-11-16 | 공공데이터포털 이용정책 | 공공기관이 저작물이 포함된 공공데이터를 제공할 때는 공공누리 유형을 붙여 이용허락 범위를 표시해야 한다고 정함 | https://www.data.go.kr/ugs/selectPortalPolicyView.do | 데이터셋마다 유형 확인 필요 |
| 2026-11-16 | 공공누리 유형 | 제2유형·제4유형은 상업적 이용 금지, 제3유형·제4유형은 변경(2차 저작물) 금지. 상업적 이용 금지 저작물은 영리행위와 직접 또는 간접으로 관련된 행위에 쓸 수 없음. 출처표시 조건 없음은 제0유형과 AI유형 | https://www.mcst.go.kr/kor/s_open/kogl/koglType.jsp?pTab=03, https://data.seoul.go.kr/etc/openInfo.do | 이 서비스는 업체의 영업에 쓰이므로 제2·4유형이면 사용 불가로 봄 |
| 2026-11-16 | 전국대형폐기물수거수수료정보표준데이터(15114146) | 상세 페이지에서 공공누리 유형과 라이선스 문구를 찾지 못함. 갱신주기 연간, 제공기관은 지방자치단체, 소관기관은 기후에너지환경부로 표시됨 | https://www.data.go.kr/data/15114146/standard.do (페이지 요약 조회 결과) | **미해소.** 이용약관 링크와 제공기관별 조건은 사람이 포털에서 직접 확인해야 함 |
| 2026-11-16 | 성남시 조례 별표, 성남시 자원순환 사이트 정책 | 검색으로 조례 별표 원문과 사이트 저작권 정책(`/guide/copyright`)을 확인하지 못함 | - | **미해소.** 사용자가 해당 페이지를 직접 확인 |

## 사용자가 직접 확인할 것 (브라우저)
1. https://www.data.go.kr/data/15114146/standard.do 에서 "이용허락범위" 또는 "이용약관" 항목에 제한이 있는지 확인합니다.
2. https://recycle.seongnam.go.kr/guide/copyright 의 저작권 정책에서 재사용 허락 범위를 확인합니다.
3. 확인 결과를 이 표 아래에 날짜와 함께 한 줄 추가합니다.
