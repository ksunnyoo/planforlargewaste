## 남은 확인과 조치 (2026-11-16)
1. 성남 절차 안내 페이지(대형 폐기물 메뉴)와 별표를 내려받은 페이지의 하단에 공공누리 제1유형 마크가 있는지 확인합니다. 있으면 화면 캡처 또는 주소를 이 기록에 추가하고, 없으면 담당부서에 사용 협의를 문의합니다.
2. 결과 화면과 공유 보기의 출처 표시(PRD F-08)에 성남시 자료는 "성남시 자원순환과, 공공누리 제1유형, 성남시 자원순환 통합 플랫폼" 형태로 넣을지 결정합니다(문구는 제1유형 표시 확인 뒤 확정).
3. 전국 표준데이터 중 실제 사용하는 지자체(평가에 쓰는 5곳 등)의 파일데이터 상세 페이지에서 이용허락범위를 한 곳씩 확인합니다. 제2·4유형이 있으면 그 지자체는 상업적 사용에서 제외합니다.

## 조치 결정 (2026-11-16 17:04, 사용자 승인: A안)
- 공개 서비스는 이용 허락이 확인된 지자체만 제공한다. 현재 허용 목록은 성남시(3780000) 하나이다.
- 구현: 환경변수 `ALLOWED_MUNICIPALITY_CODES`(쉼표 구분). 비어 있으면 제한하지 않는다(로컬 개발·평가용). Render 환경변수에는 `3780000`을 지정한다. 지자체 목록 API와 검색·분석·견적·질문 API가 허용되지 않은 지자체를 404(MUNICIPALITY_NOT_FOUND)로 거절한다.
- 평가(연구·포트폴리오 목적)는 같은 데이터로 계속 진행한다. 최종 보고서에는 "평가용 사용, 공개 서비스는 이용 허락 확인 후"로 구분해 적는다.
- 문의 결과가 오면 이 표에 날짜와 함께 추가하고, 허용되면 환경변수 목록에 코드를 더한다.
- 아직 남은 확인: 성남 마크 아이콘 확대 확인, 별표 PDF 자체의 이용 조건, 지자체별 포털 파일데이터의 이용허락범위.

## 변경 (2026-11-17 09:00 전후, 사용자 요청)
- 사용자 요청으로 공개 화면에서 다시 전국 지자체를 보여 주도록 했다(Render 환경변수 `ALLOWED_MUNICIPALITY_CODES` 해제, API 144곳 확인). 제한 코드(`license_gate.py`)는 그대로 두어 환경변수로 다시 켤 수 있다.
- 지자체 선택 화면과 결과 화면에 지자체별 이용 조건(공공누리 유형, 판정, 출처, 확인일)을 표시하도록 했다. 값은 `backend/app/core/license_info.py`에 있으며 이 기록의 확인 결과(성남 제1유형, 강남 제4유형, 해운대 표시 불일치, 수성·수원 미확인, 그 밖의 139곳 미확인)를 옮긴 것이다.
- 확인하지 못한 지자체에는 "수수료는 참고용이며 영업 목적으로 쓰지 마십시오"를 표시한다. 이용 조건이 확인되면 `license_info.py`의 항목을 추가·수정한다.
- 지자체에 이용 허락을 문의한 결과는 아직 없다.
