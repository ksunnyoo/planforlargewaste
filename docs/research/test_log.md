## 결함 목록
| ID | 심각도 | 내용 | 상태 | 조치 |
|---|---|---|---|---|
| D-01 | 주요 | 모델명이 존재하지 않아 LLM 호출이 404로 실패 | 확인 | 모델명을 환경변수로 분리하고 최신 모델로 교체, `llm_smoke.py`로 두 모델 정상 확인 |
| D-02 | 주요 | Gemini 응답이 목록 형태일 때 해석에 실패하고 조용히 저하 모드로 처리됨 | 확인 | 문자열 변환 처리(`_as_text`) 추가 |
| D-03 | 주요 | "싱글 침대" 검색에서 "받침대" 품목(거실장)이 1순위로 나옴. "3인용 소파"는 후보 없음 | 확인 | 검색 순위 단계화, 토큰별 병합, 부분문자열 보조 검색 추가(커밋 8196d0a) |
| D-04 | 사소 | "절차 복사가 안 된다"로 보고했으나 사용자가 정정, 결함 아님 | 확인 | 조치 없음 |
| D-05 | 주요 | LLM이 규격 단서 없는 입력에서 규격을 임의 선택(모호 25문항 중 10문항) | 확인 | 프롬프트 규칙 추가로 1/25로 감소. 프롬프트 예시가 평가 문항과 겹쳐 교체 |
| D-06 | 사소 | 평가 실행 시 경고(UserWarning)가 출력에 다량 표시됨 | 열림 | 결과에는 영향 없음 |
| D-07 | 사소 | 후보가 1개뿐이면 자동 선택되어 모호 입력이 확정으로 처리됨(옷장→비키니옷장 추정) | 열림 | 검증용 측정 전에는 수정하지 않음 |
| D-08 | 사소 | 무료 임베딩 한도(분당 100건, 텍스트 1건당 요청 1건)에 걸려 적재가 중단됨 | 조치 | 분당 한도에서 자동 대기·재시도, 평가에 쓰는 지자체만 적재 |
