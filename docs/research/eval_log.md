## 해석과 한계
- 모든 수치는 개발용 문항이며 프롬프트 조정에 쓰였으므로 성능 추정으로 쓰지 않습니다. 최종 수치는 검증용 문항을 1회 측정한 값만 사용합니다.
- 개발용 문항 수가 적어(매칭 45) 신뢰구간이 넓습니다. 작은 차이는 판별하지 못합니다.
- 구성 이름: 계획서의 "C3 = C2 + LLM"에 해당하는 구성은 구현에서 C4입니다(기존 C3 결과를 유지하기 위해 새 이름을 썼습니다). C3는 trigram + LLM입니다.
- 임베딩은 평가셋에 쓰이는 5개 지자체(3780000, 3740000, 3220000, 3330000, 3460000)의 품목만 적재했습니다(Gemini 무료 한도: 분당 100건, 텍스트 1건당 요청 1건).
- 개발용 41줄은 검색 지표(recall)가 모든 구성에서 천장(1.0)에 닿아, 검색 방식 간 차이를 구별하지 못합니다. 정확 확정 수는 LLM 선택 여부(C3·C4 16/16 대 12/16)로만 갈립니다.
- 충실도 판정(L3 Faithfulness)과 결과 일치(L4)는 아직 구현하지 않았습니다.
