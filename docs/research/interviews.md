# 업체 인터뷰 (가상 설정 + 질문지)

> **이 문서의 "가상 응답"은 실제 인터뷰 결과가 아니라 가설입니다.** 페르소나(PRD 3절)와 KPI를 구체화하고 인터뷰 때 무엇을 확인할지 정하기 위한 시나리오입니다. 실제 인터뷰를 하면 아래 기록 서식으로 **추가**하고, 가상 설정은 수정하지 않습니다. 근거로 인용할 때는 반드시 "가설"이라고 표기합니다.

## 1. 인터뷰 대상 (실제 섭외 기준)
| 구분 | 기준 |
|---|---|
| 대상 | 성남시 및 인근에서 이사·정리·폐기물 처리를 하는 업체의 견적 담당자(대표, 실장) |
| 인원 | 2~3명, 1인당 5~10분(전화) |
| 섭외 | 사용자가 직접 연락처를 확보 (연락처 정보는 이 문서에 기록하지 않음) |
| 사전 안내 | 개인정보와 고객 정보는 말씀하지 않도록 안내 |

## 2. 질문지
1. 고객 1건의 대형폐기물 견적을 내는 데 보통 얼마나 걸립니까? 어떤 순서로 하십니까?
2. 지자체 수수료는 어떻게 확인하십니까? (사이트, 전화, 기억 등)
3. 고객이 말하는 물건 이름과 공식 품목명이 달라 곤란했던 경우가 있습니까?
4. 수수료를 잘못 안내해서 문제가 생긴 적이 있습니까?
5. 한 달에 대략 몇 건을 처리하십니까?
6. 지자체 수수료와 업체 작업비를 구분해 고객에게 설명하십니까?
7. 이런 도구가 있다면 어떤 화면과 결과물이 필요합니까? (공유 링크, 인쇄 등)
8. 이용 비용(월 구독 또는 건별)이 있다면 어느 정도까지 고려하시겠습니까? (금액은 유도하지 않고 열린 질문으로)

## 3. 가상 설정 (가설, 실제 인터뷰 아님)
| 항목 | 가상 설정 |
|---|---|
| 인물 | 박정훈 실장(PRD 3.1) 유형: 이사·정리 업체 견적 담당 |
| 업무 방식 | 전화·문자로 고객 물건을 들은 뒤 사이트나 기억으로 수수료를 찾아 합산 |
| 불편 | 품목명 표기 차이로 찾는 데 시간이 걸림, 규격 선택 실수 우려, 고객에게 근거를 보여 주기 어려움 |
| 기대 | 후보 제시 + 확정, 지자체 수수료와 작업비 분리 표시, 링크 공유 |
| 우려 | AI가 틀린 금액을 단정하는 것 |

## 4. 가설 검증 연결
| 가설 | 확인 질문 | 판단 기준 |
|---|---|---|
| H1 조회 시간 단축 | 1, 2, 3 | 현재 소요 시간 확인 후 단축률 목표 설정 |
| H2 후보 + 확인 구조 | 4, 7 | 확인 단계를 불편이 아니라 안전장치로 보는지 |
| H3 수수료·작업비 분리 | 6 | 고객 설명에 쓸 수 있다고 응답 |
| H4 지불 의사 | 8 | 지불 의사 표현 여부 |
