# 공공데이터포털 이용약관·데이터 이용조건 정리

| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.2 (초안, 성남시 자료 현황 갱신) |
| 작성일 | 2026-11-13 |
| 성격 | 공공데이터포털 이용약관·이용정책을 **이 프로젝트 관점에서 요약한 정리본**입니다. 본 서비스의 자체 이용약관이 아니며, 법률 자문이 아닙니다. |
| 근거 | 공공데이터포털 이용약관 페이지(https://www.data.go.kr/ugs/selectPortalPolicyView.do), 데이터셋 상세 페이지 |

> 표기 규칙: **[검증 필요]** 는 원문을 직접 확인해야 하는 사항입니다. 아래는 2026-11-13에 확인한 요약이며 약관은 변경될 수 있으므로 상업화 전에 원문을 다시 확인하십시오.

## 1. 이용약관의 구조
이용약관은 17개 조문(목적, 용어의 정의, 약관의 효력과 변경, 약관외 준칙, 이용 계약의 성립 및 제한, 회원정보 사용에 대한 동의, 회원의 정보 보안, 서비스 이용시간, 서비스 중단, 게시물의 관리, 서비스의 이용제한, 회원, 센터, 제공기관, 지식재산권, 면책조항, 관할법원)으로 구성됩니다.

## 2. 데이터 이용 조건은 어디에 있는가
- 이용허락, 상업적 이용, 출처표시는 이용약관 조문이 아니라 **「이용정책」의 공공데이터 이용허락범위와 공공누리 유형표**에서 다룹니다.
- 따라서 데이터셋마다 부착된 **이용허락범위(공공누리 유형)** 를 각각 확인해야 합니다.

| 공공누리 유형 | 상업적 이용 | 출처표시 | 변경(2차 저작물) |
|---|---|---|---|
| 제0유형 | 가능 | 조건 없음 | 가능 |
| 제1유형 | 가능 | 필요 | 가능 |
| 제2유형 | **불가** | 필요 | 가능 |
| 제3유형 | 가능 | 필요 | **금지** |
| 제4유형 | **불가** | 필요 | **금지** |
| AI유형 | 가능 | 조건 없음 | 가능 |

## 3. 약관 중 본 프로젝트와 관련되는 조항
| 조문 | 내용 | 프로젝트 영향 |
|---|---|---|
| 제12조 제4항·제5항 | 타인의 지식재산권 침해, 포털의 정상 운영 방해 등을 금지하고, 위반 시 이용 제한·계약 해지·손해배상 청구가 가능 | 서버에서 포털 API를 반복 호출하지 않고, 데이터를 **사전에 적재**해 사용합니다(SDD 6절). |
| 제14조 제4항·제5항 | 제공기관은 이용요건 위반 시 데이터 제공을 중단할 수 있고, 오픈 API 이용이 시스템 성능에 지장을 주면 이용을 제한할 수 있음 | 적재 스크립트는 로컬에서 1회성으로 실행하고 호출 간격을 둡니다. |
| 제15조 제2항 | 자료실 게시정보는 공공데이터 제공결정을 거친 것이 아니며 제3자 지식재산이 포함될 수 있음 | 자료실이 아닌 **표준 데이터셋**만 사용합니다. |
| 제15조 제3항 | 센터의 사전 승인 없이 포털의 지식재산을 이용하거나 제3자에게 이용하게 해서는 안 됨 | 포털의 로고·디자인을 서비스에 사용하지 않습니다. |
| 제16조 제2항 | 제3자 권리가 포함된 사실을 알고 이용한 경우 면책 대상에서 제외 | 제3자 권리 표기가 있는 데이터는 사용하지 않습니다. |

## 4. 본 프로젝트가 사용하는 데이터의 이용조건 현황
| 데이터 | 확인된 내용 | 상태 |
|---|---|---|
| 전국대형폐기물수거수수료정보표준데이터(data.go.kr/15114146) | 상세 페이지에 라이선스·이용허락 조건이 명시되어 있지 않고 약관 링크만 있음. 제공기관 143곳이 병합된 데이터로, 기관별 이용허락범위가 다를 수 있음 | **[검증 필요]** 포털에서 이용허락범위 항목을 직접 확인 |
| 지자체 개별 데이터셋(예: 경기도 하남시 대형폐기물 수거품목 정보) | 해당 데이터셋은 "이용허락범위 제한 없음"으로 표시됨 | 데이터셋마다 다르므로 개별 확인 |
| 성남시 수수료 기준(별표 1 PDF) | 성남시가 배포하는 조례 별표(사용자 제공). 근거 조례 「성남시 폐기물 관리에 관한 조례」(시행 2026.10.26) | **[검증 필요]** 재사용 허락, 최신 별표와의 일치 |
| 성남시 자원순환 사이트(recycle.seongnam.go.kr) 절차 안내 | 사이트가 자동 수집을 제한하여 사용자가 내용을 직접 복사해 제공(`data/raw/seongnam_procedure.md`) | **[검증 필요]** 사이트 저작권 정책(`/guide/copyright`) 확인 |

## 5. 서비스 적용 체크리스트
1. 사용할 데이터셋마다 이용허락범위(공공누리 유형)를 기록합니다. 제2·4유형이면 상업화에 쓰지 않습니다.
2. 출처표시가 필요한 유형이면 결과 화면과 공유 보기에 출처(제공기관명, 데이터셋명, 기준일)를 표시합니다(PRD F-08).
3. 변경 금지(제3·4유형) 데이터는 가공 없이 원문 그대로 표시할 수 있는지 확인합니다. 정제·정규화·임베딩 가공이 변경에 해당하는지는 **[검증 필요]** 입니다.
4. 데이터 이용 확인 결과를 `docs/research/data_license_log.md`에 날짜와 함께 추가합니다(수정 없이 추가만).
5. 상업화 전에는 제공기관 143곳 중 실제 사용하는 지자체의 조건을 다시 확인합니다.
